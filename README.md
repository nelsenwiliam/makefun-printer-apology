An entry for the [make.fun](https://make.fun) bounty
[The Printer Apology](https://make.fun/bounty/u-eager-stork-81-9647-the-printer-apology-60229153):
a program that writes one line — an apology note from an office printer
to the people who keep jamming it, feeding it cheap paper and swearing
at it — to `/output/entry.txt`.

## The line

> Sorry for the jam, the streaks, the burnt-toner smell. HR says I can't file a complaint about you.

## Run

```sh
python3 main.py
```

Pure standard library; the program writes `/output/entry.txt` and
nothing else.
